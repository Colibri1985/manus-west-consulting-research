# Изменения v2 относительно v1

1. Состав ZIP и MANIFEST согласован автоматически. build-context/.dockerignore явно включён и проверен по имени и SHA-256 после создания архива. Служебный prepare_bundle.py исключён из поставки и списка файлов намеренно: не нужен Docker-сборке; объяснение в README и MANIFEST.exclusions.
2. Контракт local_command получен из публичных OCI-слоёв ТОЧНОГО закреплённого образа. Не используется main как доказательство версии. Различены index digest, platform manifest и Docker image ID. Добавлены исходники, layer provenance и SHA выбранных файлов.
3. Добавлен integration_test.py: штатный Hermes transcribe_audio → local_command → реальный STT runner → txt → структурированный результат. Конфиг синтетический, без Telegram/рабочих секретов; исполнение только после отдельного согласования. Добавлены негативные сценарии. Модель/образ сейчас не запускались.
4. control.py выполняет тесты по immutable image ID и записывает только реальные успешные receipts. При повторном тесте прежний PASS инвалидируется. switch.sh требует две успешные receipts и совпадение image ID, build inputs, manifest пакета, модели, identity, preflight и исходных Compose/config. Изменение/отсутствие блокирует switch до config apply.
5. Адресный анализ разрешений: исходный handler вызывает subprocess напрямую, не terminal tool; глобальная автоустановка в маршруте не нужна. Новый policy_probe проверяет live bool/PM-policy read-only и под эффективной identity gateway, но сейчас НЕ запускался. Test uid/gid и существующие группы берутся только из фактов, новые права не выдаются.
6. Исправлены формулировки: каждое распознавание загружает модель в новом процессе; повторный проход не warm run. Audit hook не изолирует native network; тесты используют --network=none. Откат после ошибки — ручной. Постоянное пересоздание требует четвёртого Compose-файла; после switch он закрепляет точный протестированный image ID.
7. Прежняя архитектура, pinned зависимости, модель base, рабочие конфиги и gateway не изменены. Архив v1 сохранён отдельно.

## Что не объявлено выполненным

Docker build, pip install, загрузка модели, inference, live policy probe, запуск на VPS, переключение и перезагрузка не выполнялись. Проверки пакета/контракта с тестовыми двойниками не являются успешными ASR-тестами и не порождают acceptance receipts.
