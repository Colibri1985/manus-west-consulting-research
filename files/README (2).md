# VBA-пилот: готовый модуль, один импорт и один запуск

## Зачем
Проверить код, подготовленный Афиной: макрос должен сам прочитать два наших тестовых источника, создать новую книгу сравнения, записать и пересчитать формулы Excel, а затем проверить результаты на отдельном листе Checks. Это проверка выполнения VBA в Excel 2021, не продолжение ручного ввода ячеек.

## Статус
Пробный модуль согласован Андреем для подготовки и последующего ручного запуска. Нативная компиляция и выполнение VBA на сервере не производились. Доставка текстового модуля и наличие защитных конструкций проверяются статически; эти проверки не доказывают работоспособность кода в Excel. Приёмка — только после местного запуска.

## Объём и безопасность
- Только AuditSourceA.xlsx и AuditSourceB.xlsx из %LOCALAPPDATA%\AthenaExcelTest.
- Источники должны быть закрыты перед запуском. Уже открытые источники макрос не закрывает и не переиспользует: останавливается с пояснением.
- Открытие источников: ReadOnly=True, UpdateLinks=0. Чтение только числового диапазона AuditInputs = Data!B2:B4.
- Источники закрываются без сохранения. Старые модели и книга Power Query не изменяются.
- Создаётся новая НЕСОХРАНЁННАЯ книга с листами BudgetCompare и Checks. Файлы автоматически не записываются.
- Нет сетевых запросов, команд оболочки, доступа к VBA-проектам из кода и изменений настроек Центра управления безопасностью.
- На время программного открытия источников Application.AutomationSecurity временно переводится в более строгий режим ForceDisable (3), затем восстанавливается прежнее значение, в том числе по обработчику ошибки. Это не отключение защиты и не постоянная перенастройка Excel.
- Перед началом макрос отдельно спрашивает подтверждение описанного действия. При отмене ничего не открывает и не создаёт.
- Исходник модуля содержит только ASCII, чтобы при импорте VBA не возникало ошибок кодировки кириллицы. Заголовки отчёта и сообщения поэтому на английском.

## Запуск
1. Сохранить приложенный AthenaBudgetPilot.bas на компьютер. Двойной щелчок по нему не запускает наш тест.
2. Убедиться, что оба источника закрыты. В Excel создать НОВУЮ пустую книгу — она будет временным носителем макроса.
3. Нажать Alt+F11. В редакторе VBA слева выбрать проект именно новой пустой книги, а не рабочей модели.
4. Нажать Ctrl+M (File → Import File) и выбрать AthenaBudgetPilot.bas. Импортировать модуль целиком. Не вставлять строку Attribute VB_Name в окно кода вручную.
5. Вернуться в Excel через Alt+Q. Нажать Alt+F8, выбрать AthenaBudgetPilot и нажать «Выполнить».
6. Прочитать подтверждение макроса и нажать OK, если объём соответствует согласованному тесту. При запрете запуска или ошибке ничего глобально не разрешать — сообщить точный текст.

Не включать «Разрешить все макросы», «Доверять доступ к объектной модели проектов VBA», доверенные папки и другие глобальные исключения. Если политика Excel запрещает запуск, останавливаемся и разбираем конкретное ограничение отдельно.

## Ожидаемый результат
Новая книга, лист BudgetCompare:
- Source_A: 100, 200, 300; TOTAL = 600.
- Source_B: 110, 220, 330; TOTAL = 660.
- Delta: 10, 20, 30; TOTAL = 60.
- Delta_pct: 10%; итог = 10% (в таблице может отображаться 10,0%).

Числа источников считываются из файлов. Итоги и отклонения в отчёте — формулы Excel, а не заготовленные ответы. Ожидаемые 600, 660, 60 и 0,1 используются отдельно только для контроля.

На листе Checks должны быть PASS по всем 12 контрольным строкам. Среди проверок: источники открывались на чтение, формулы пересчитались, суммы совпали с независимым циклом VBA, внешних Excel-связей в новом отчёте нет, итоговые ячейки остались формулами.

В случае PASS достаточно прислать снимок BudgetCompare и Checks или подтвердить итог 600 / 660 / 60 / 10% и отсутствие FAIL. В случае ошибки — точный текст сообщения; код правит Афина, а не Андрей по строкам.

Результат можно отдельно сохранить как AthenaVbaBudgetResult.xlsx в тестовой папке: в новой книге отчёта макроса нет. Книгу-носитель не сохранять поверх существующих файлов. Её можно закрыть без сохранения после теста: исходник модуля остаётся в .bas.

## Границы
Этот пилот не доказывает сохранность объектов сложных существующих моделей, не тестирует Power Pivot и не означает готовность любого VBA-кода. Рабочие книги не участвуют.
