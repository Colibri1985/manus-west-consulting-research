# Power Query: первый запуск готового запроса Афины

## Цель
Проверить, что подготовленный Афиной M-код выполняется в Excel Андрея: самостоятельно читает именованный диапазон AuditInputs из двух файлов и создаёт контрольную таблицу. Это не проверка сохранности Power Query при стороннем пересохранении книги и не работа с рабочими моделями.

## Статус
Подготовлен код. Нативный запуск Power Query на сервере не выполнен: доступного движка Power Query здесь не установлено. Функции Excel.Workbook, File.Contents и List.AllTrue сверены с официальной документацией Microsoft. Ожидаемые результаты рассчитаны по реально присланным источникам, а не придуманы. Нативная проверка остаётся на локальном Excel; считать код прошедшим приёмку до неё нельзя.

## Что делает запрос
- Читает только AuditSourceA.xlsx и AuditSourceB.xlsx из C:\Users\Admin\AppData\Local\AthenaExcelTest\.
- Находит объект AuditInputs с Kind=DefinedName.
- Требует один столбец, три строки и числовые значения без пустых ячеек.
- Рассчитывает сумму из реально прочитанных значений через List.Sum.
- Сравнивает её с явным контрольным ожиданием; столбец ActualSum НЕ заполняется константой.
- Возвращает две строки Source / InputName / RowCount / ActualSum / ExpectedSum / Status.
- Не изменяет, не сохраняет и не открывает на запись книги-источники. Не использует макросы, сеть и внешние библиотеки.

Ожидаемая таблица:
- AuditSourceA.xlsx / AuditInputs / 3 / 600 / 600 / OK.
- AuditSourceB.xlsx / AuditInputs / 3 / 660 / 660 / OK.

## Один запуск
1. Создать новую пустую книгу. Четыре прежних файла не изменять. Источники можно оставить закрытыми.
2. Данные → Получить данные → Из других источников → Пустой запрос.
3. В редакторе Power Query открыть «Расширенный редактор». Удалить его начальный шаблон и вставить ВЕСЬ текст AthenaAudit.pq. Файл .pq — обычный текст: его можно открыть в Блокноте. Это не книга Excel и не готовое подключение, которое нужно импортировать двойным щелчком.
4. Нажать «Готово». В предварительном просмотре должны появиться две строки с результатами выше.
5. «Закрыть и загрузить» в новую книгу. При необходимости сохранить новую книгу как AthenaPowerQueryTest.xlsx в тестовую папку.

Если интерфейс предлагает иной выбор или возникает ошибка, не менять глобальные настройки доверия и конфиденциальности; передать точный текст ошибки. Для проверки достаточно результата целиком или одного снимка таблицы. Существующие рабочие запросы не открывать и не заменять.

## Критерии приёмки
- Запрос исполнился в Excel, а не только был вставлен в редактор.
- В результате две строки с правильными именами файлов, RowCount=3, ActualSum=600 и 660, Status=OK.
- Повторное «Обновить всё» возвращает те же результаты без ошибок.
- Исходники и прежние модели не редактировались.

Критерии ещё не выполнены локально и требуют подтверждения Андрея. Серверная сверка исходных данных не заменяет выполнение M-кода.
