БДДС — Прототип v2 (функциональный)

Автономный HTML. Реальные статьи из Shablon-BDDS.xlsx (`701.201`, `702.0101` и др.). Сохранение/восстановление бюджета в JSON.

Несохранённые изменения

Реестр операций (добавление, редактирование, удаление)

Каждая запись: постоянный ID, статья (из справочника), направление (поступление / выплата), дата, сумма, описание.

Работающие функции: добавление, редактирование (двойной клик по строке или кнопка «Изменить»), удаление с подтверждением. При исправлении ID сохраняется; связанные денежные события заменяются.

БДДС — помесячный денежный поток

События агрегируются по месяцам. Группы суммируют дочерние статьи. Остаток = предыдущий + поступления − выплаты.

Статья / ГруппаМесяц 1Месяц 2Месяц 3Итого
Правило знаков: поступления положительные, выплаты отрицательные. Группы (`.000`) суммируют дочерние. События вне периода отображаются в списке отдельно.

Экспорт, сохранение и статус системы

Полностью работающие функции: сохранение бюджета в JSON; открытие JSON; проверка обязательных параметров; индикатор несохранённых изменений; регистрация операций; удаление с подтверждением; агрегирование БДДС по месяцам с остатками.
Незавершённые требования исходного задания (по состоянию на этот файл): полноценный справочник материалов с категориями (электротехнические, сантехнические, общестроительные, для клининга) с описанием `materialDescription` до 2000 символов; полный календарь работ с сезонными окнами и короткими месяцами; автоматическое создание связанных расходов для КУ; проверка всех финансовых итогов (реестр = БДДС = Dashboard); экспорт проверочного XLSX с защитой текстов как формул; сметная детализация; адаптер БИТ (статус «Требуется подтверждённый формат»); налоговый профиль с подтверждением ставок по году; заполнение всех семи вкладок до уровня производственного использования.
Не реализовано автоматически: автоматическое распределение статей в новые подстатьи; формула маржи (`расход = доход / (1 + %/100)`) требует ручного ввода параметра; рабочий календарь (рабочие дни) отключён; индивидуальные налоговые пороги не применяются.
