## 7. Подготовленный диагностический скрипт

Executor: /var/lib/hermes/workspace/projects/athena-diagnostics/inventory_readonly.py.
Хост: /srv/hermes-agent/telegram-data/workspace/projects/athena-diagnostics/inventory_readonly.py.

Скрипт выполняет docker inspect только известных трёх контейнеров, docker exec для чтения allowlisted-полей и Git-команды только чтения без optional locks. Он не запускает doctor/setup, tool handlers, MCP, вызовы моделей, миграции или перезапуски; не читает журналы, разговоры или содержание файлов памяти; не выводит Docker ENV и полный конфиг.

Пять локальных тестов прошли: фильтрация чувствительных полей, неизменность тестовых файлов, подсчёт навыков без заявления об активации, отсутствие утечки текста исключений, фильтрация Docker ENV и лишнего stdout.

Пробный запуск в executor честно вернул FileNotFoundError для Docker и не получил данных gateway. Это ожидаемое ограничение среды, а не результат обследования хоста.
