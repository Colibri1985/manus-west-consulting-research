# Афина 2.0 — единый выпуск архитектуры3.2

Предметное изменение: Kaiten включён архитектурно и методологически как планируемая интеграция. Ранее рабочее подключение не утверждается. Выбор framework и остальных компонентов не изменён этим выпуском.

## Документы
Athena_2_0_Current_Specification_v3_2.md — основной структурированный текст, 35 разделов.
Athena_2_0_Current_Specification_v3_2.docx — основной Word-документ, текст + PNG схемы.
Athena_2_0_Current_Specification_v3_2.doc — дополнительная Word-совместимая RTF версия (не бинарный Word97 .doc). Имя .doc сохранено для удобства запроса; рекомендуется .docx. Возможное предупреждение о формате связано с этим, а не с макросами. VBA/macros не включены.
