Пакет задания для Афины / Hermes Agent

1. Прочитать ТЗ (Markdown — основной машиночитаемый текст, Word — для согласования).
2. reference_contract.json содержит точный initialState, все статьи, DOM-поля, функции, контрольные расчёты и аудит встроенного XLSX.

Fixtures фиксируют исходный алгоритм, включая известные округления. Не смешивать baseline и исправленные результаты.
Наличие документа не означает согласование всех предложенных исправлений. В ТЗ явно отмечены точки согласования.
