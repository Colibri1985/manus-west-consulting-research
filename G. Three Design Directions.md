# G. Three Design Directions

**Назначение:** текстовые art directions для будущего сайта и презентаций. Это не макеты и не спецификация final brand identity. Все варианты поддерживают характер бренда: **senior, premium, calm, analytical, human, trusted, Russian B2B, modern but timeless**.

## Direction 1 — «Финансовая карта»

| Аспект | Решение |
|---|---|
| Стратегическая роль | Показать, что West связывает разрозненные данные, людей и решения в понятную карту действий. |
| Mood | Спокойный аналитический кабинет; интеллектуальная ясность, а не «банковский контроль». |
| Визуальная метафора | Контуры, слои, маршруты и точки решения на карте финансовой управляемости. |
| Палитра | Тёплый off‑white #F6F3EC; graphite #202520; глубокий forest‑blue #173A42; muted sage #7A948B; редкий amber signal #B9823E. |
| Типографика | Выразительный, но читабельный serif для ключевых тезисов; спокойный neo‑grotesk для текста и интерфейса; tabular numerals только в таблицах. |
| Сетка | 12‑колоночная desktop grid, широкие поля; mobile — один контентный поток с короткими блоками. |
| Иерархия | Большой problem statement → evidence / decision map → calm CTA. Не больше одного визуального «сигнала риска» на экран. |
| UI language | Тонкие карты‑линии, сдержанные карточки, аккуратные labels «Проблема / Решение / Граница». |
| Иконки / иллюстрации | Геометрические маркеры, слои и маршрутные схемы; минимум literal icons. |
| Motion | Slow reveal связей при scroll; подчеркнуть порядок появления решения. Нет counters, bouncing CTA, «trading» animations. |
| Desktop/mobile | Desktop показывает relationship map и side notes; mobile превращает её в sequence cards, а не в мелкую диаграмму. |
| Преимущества | Сильный bridge между CFO, methodology и automation; хорошо поддерживает tool‑neutral позицию. |
| Риски | Слишком много сеток/линий создаст вид «консалтинг ради консалтинга». |
| Когда использовать | Главная, automation advisory, methodology/deck для partner conversations. |
| Чего избегать | Синих «кибер» градиентов, pseudo‑BI dashboards, финансовых графиков без контекста. |

## Direction 2 — «Тихая точность»

| Аспект | Решение |
|---|---|
| Стратегическая роль | Создать доверие к человеку‑эксперту до появления логотипов, громких кейсов и команды. |
| Mood | Взрослая уверенность, аккуратность, честные границы, спокойствие senior advisor. |
| Визуальная метафора | Хорошо составленная записка CFO: ясный вопрос, проверенные факты, следующий шаг. |
| Палитра | Stone #EFECE6; ink #242628; steel‑blue #536A76; muted copper #A77957; white #FFFFFF. |
| Типографика | High‑contrast serif для первых строк и цитат; humanist sans для длинных русских текстов; generous line height. |
| Сетка | Editorial grid с разными ширинами колонок; крупные поля; композиция строится на ритме текста, а не плитках. |
| Иерархия | Один тезис на блок; деликатные eyebrow labels; proof/limits рядом с claim. |
| UI language | Нумерованные steps, understated rules, good tables, short annotations; формы выглядят как спокойная переписка, не лид‑машина. |
| Иконки / иллюстрации | Собственные абстрактные marks, документные детали, аккуратная портретная фотография; без фото «рукопожатий». |
| Motion | Очень сдержанная fade/slide логика; уважение к предпочитаемому reduced motion. |
| Desktop/mobile | Desktop — editorial columns и pull quotes; mobile — одна колонка, larger text, no fragile layouts. |
| Преимущества | Лучший вариант для личного бренда, method pages, trust before proof. |
| Риски | Можно стать слишком «мягким» и потерять операционную ясность; требуется сильный CTA copy. |
| Когда использовать | Главная, о практике/Андрее, диагностическая услуга, материалы. |
| Чего избегать | Lifestyle‑luxury, excessive beige, handwritten fonts, vague poetry вместо scope. |

## Direction 3 — «Контур управления»

| Аспект | Решение |
|---|---|
| Стратегическая роль | Показать систему управления без имитации generic SaaS: данные → роль → решение → действие → review. |
| Mood | Собранность, ответственность и операционная зрелость. |
| Визуальная метафора | Замкнутый управленческий цикл, в котором каждый input имеет owner и каждое отклонение — следующий шаг. |
| Палитра | Clean white #FAFAF8; deep navy #102E42; slate #60727E; sage #A8B9A9; restrained amber #C8923A. |
| Типографика | Строгий grotesk с хорошей кириллицей; accent serif только для длинных manifesto lines. |
| Сетка | Модульная grid, process strips, tables, multi‑step cards; desktop 12 columns, mobile 4 columns. |
| Иерархия | Hero → «что происходит» → «как работа устроена» → «кто за что отвечает» → CTA. |
| UI language | Process maps, status tags, RACI‑like matrices, clear dividers. Каждая visual часть отвечает на вопрос, а не декорирует. |
| Иконки / иллюстрации | Простейшие system icons, human‑free diagrams, control‑loop patterns. |
| Motion | Step‑by‑step progression, subtle state change. Нет spinning loaders, neon edges или gamification. |
| Desktop/mobile | Desktop — горизонтальные process maps; mobile — вертикальные steps with sticky context label. |
| Преимущества | Сильнее всего для automation advisory, partners и productized services. |
| Риски | Может стать «корпоративным IT‑сайтом» и ослабить личное доверие. |
| Когда использовать | Automation, partner, «Финансы под контролем», презентация method/roadmap. |
| Чего избегать | Псевдо‑SaaS hero, fake KPI widgets, robot illustrations, fluorescent green. |

## Общие дизайн‑ограничения

1. **Не использовать:** crypto aesthetic, neon, robots, fake dashboards, stock handshakes, generic SaaS trope, urgency pop‑ups, countdown, dark‑pattern checkboxes.
2. **Не создавать доказательства визуально:** график или dashboard не может имитировать реальную клиентскую аналитику; все demo artifacts маркировать как illustrative.
3. **Accessibility:** контраст текста не ниже practical AA, focus states, reduced motion, readable Cyrillic, mobile form targets.
4. **Privacy by design:** в mockups и future materials не показывать real client data, emails, invoices, logo marks, bank balances или screenshots без permission.
5. **Выбор направления:** рекомендованный base — «Тихая точность»; «Контур управления» — для automation/partner pages; «Финансовая карта» — как diagram system. Это **РЕКОМЕНДАЦИЯ**, не факт о предпочтениях аудитории.
