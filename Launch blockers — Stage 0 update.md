# Launch blockers — Stage 0 update

These blockers are separated by owner decision, incomplete implementation and external approval. They do not all block Stage 1 mockups, but they do block a production-ready claim.

## Owner decisions

- [ ] Approve Stage 1 desktop/mobile mockups for the hybrid visual system.
- [ ] Choose the long-term source of truth: static content/build layer, Astro, or WordPress.
- [ ] Decide canonical diagnostic route and treatment of the legacy root page.
- [ ] Approve whether Cash & Finance Review is a real standalone scope or only a scenario recommendation.
- [ ] Confirm the production contact/CRM architecture and allowed data route.
- [ ] Approve final homepage and service copy before production publication.

## Incomplete implementation

- [ ] Consolidate homepage and internal pages into one shared design token/component layer.
- [ ] Fix mobile menu open/close, ARIA state, focus handling, Escape and hidden-link keyboard behavior.
- [ ] Repair generator drift or explicitly archive the generator and introduce one reproducible build.
- [ ] Remove divergent diagnostic versions from active navigation; preserve compatibility intentionally.
- [ ] Add four scenario detail pages.
- [ ] Add Cash Risk Check with transparent 12-question demo logic.
- [ ] Add legal placeholder routes and real 404 handling in deployment configuration.
- [ ] Standardize form names, labels, validation, intents, consent and truthful demo result.
- [ ] Add SEO infrastructure: canonical config, sitemap, robots, OG and staging noindex.
- [ ] Add reproducible checks for routes, anchors, duplicate IDs, labels and build output.
- [ ] Perform browser/manual accessibility and responsive checks at all required viewports.

## External/legal/content approval

- [ ] Final privacy policy and personal-data consent text.
- [ ] Cookies notice and analytics consent logic.
- [ ] Requisites and terms/offer text.
- [ ] Approved founder biography and any schema Person data.
- [ ] Approved article authorship, dates, sources and publication status.
- [ ] Approved permissions for any future cases, testimonials, logos or results.
- [ ] Approved commercial pricing formula and tariff conditions.
- [ ] Production domain, hoster, HTTPS and deployment/rollback environment.
- [ ] Bitrix24/server-side form access and data-processing review.
- [ ] Analytics/event map approval.

## Explicitly not connected

- GitHub Pages;
- production domain;
- CRM;
- email notifications;
- analytics/pixels;
- payment or paid external services;
- real form delivery.
