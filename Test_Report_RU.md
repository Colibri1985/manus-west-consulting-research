# Испытание Perplexity Presentation Studio 0.1.1

## Итог

Код действительно испытан без установки навыка. Сборка нового PPTX работает; ограниченные автоматические проверки и проверки отклонения неправильного review выполняются. Полный новый цикл PPTX → PDF → PNG → визуальная проверка на этом исполнителе НЕ завершён: новый PDF не получен. Это результат испытания ограниченного прототипа, не приёмка production-навыка.

## Разрешение и стенд

Андрей отдельно разрешил запуск копий кода в `/var/lib/hermes/workspace/isolated-tests/`, без установки пакетов, изменений активных навыков и ремонта renderer.

Каталог этого запуска: `/var/lib/hermes/workspace/isolated-tests/perplexity-v011-dz_1e6l7/`.

- Код скопирован из проверенного архива в отдельный каталог.
- Использован существующий Python Office-окружения, не основной Python Hermes.
- HOME, TMPDIR, кэш и конфигурация Fontconfig локальны для стенда.
- Использованы существующие приватные библиотеки и шрифты; новые компоненты не устанавливались.
- Для дочернего Python заданы лимиты CPU, памяти, размера файлов и запрет core dump.
- Python audit hook ограничивает запись каталогом стенда, запрещает сетевые вызовы Python и ограничивает запуск дочерних программ.

Это НЕ контейнер и НЕ полноценная защитная песочница: audit hook не обеспечивает системную изоляцию нативных библиотек или дочерних программ. Docker/Podman не обнаружены; проба создания Linux namespaces получила Operation not permitted. Ограничения честно сообщены до запуска, размещение стенда согласовано отдельно. Запрет инструмента записи в /tmp не обходился и не отключался.

## Что выполнено

### 1. Тесты автора без изменения

Запущен исходный `scripts/test_studio.py`: 8 тестов, общий результат FAILED. Причина препятствия — пример тестов требует DejaVu Sans, которого нет в используемом наборе шрифтов. Fontconfig предлагает другой шрифт, но прототип отклоняет его: `Required font missing: DejaVu Sans`.

Это не доказательство сломанной сборки. Проверка отсутствующего шрифта действительно предотвращает скрытую подстановку. Однако тесты пакета не переносимы без удовлетворения их шрифтового условия.

### 2. Те же проверки на приложенном Liberation Sans-примере

Создана отдельная копия тестового файла. Единственное изменение — выбор уже приложенного `examples/demo.json` вместо `examples/demo_local_dejavu.json`. Проверяемые утверждения не менялись, код сборщика не менялся.

Результат: **8 из 8 пройдены**, затем повторный запуск также прошёл. Это относится к адаптированной тестовой фикстуре, а не к исходному DejaVu-набору.

Проверяются валидная спецификация, согласование, повторяющиеся ID, неподдерживаемый layout, сборка/запрет перезаписи, переполнение, изменение PPTX и запрет review до рендера.

### 3. Новый артефакт

Собран новый PPTX на 3 слайда с Liberation Sans. Повторное чтение подтвердило 3 слайда и 3 части заметок; имя шрифта дополнительно сверено по XML. Это проверка содержимого и структуры, не визуальная проверка.

### 4. Экспорт нового PPTX

Был выполнен реальный вызов комплектной функции render с существующим приватным LibreOffice. Получен отказ `ValueError: PDF export failed`; нового PDF нет. Manifest сохранил `build_status=success`, `render_status=failed`, `visual_review_status=not_reviewed`, `delivery_status=draft`.

В stderr LibreOffice присутствует предупреждение о javaldx. Это не установленная причина сбоя. Runtime не ремонтировался; точная причина отказа экспорта здесь не установлена. Скрипт прототипа не сохраняет код возврата дочернего конвертера в manifest, поэтому точный native exit code этому запуску не приписывается.

Первый пробный запуск рендера был заблокирован собственным audit guard стенда из-за обработки posix_spawn. Проблема воспроизведена отдельной регрессией; в стенде разрешены только конкретные существующие исполняемые файлы Fontconfig/LibreOffice. После исправления стенда регрессия прошла и произведён отдельный реальный вызов конвертера, описанный выше. Это не ошибка кода Perplexity и не исправление LibreOffice.

### 5. Работа review

На отдельных копиях ПРИЛОЖЕННОГО автором тестового результата, а не нового Liberation Sans-PPTX, проверены:

- неполный review → отклонён с Incomplete review;
- чужой run_id → отклонён с Stale review;
- изменённый PNG → отклонён с PNG changed;
- собственный отчёт после фактического просмотра приложенных PNG → принят, итог needs_fixes.

Все три изображения автора действительно просмотрены через vision_analyze. Замечания:

- Слайд 1: карта ролей названа этапами — уточнить формулировку.
- Слайд 2: подписи переходов оторваны от стрелок между карточками; неудачные смысловые переносы; одиночное слово в конце вывода.
- Слайд 3: подзаголовок о будущем развитии не соответствует карточкам с ограничениями.

Видимого переполнения на приложенных PNG не обнаружено. Замечания не являются доказательством дефектов новой Liberation Sans-сборки: для неё свежего рендера нет.

## Предварительная независимая проверка поставки

До исполнения кода проверены 21 запись PACKAGE_MANIFEST.json: несовпадений не обнаружено. В архиве 22 файла с учётом самого manifest. Хеши спецификации, PPTX, PDF и трёх PNG согласованы. PDF содержит 3 страницы; независимая растеризация существующего PDF дала точное совпадение декодированных пикселей с каждым приложенным PNG.

Это подтверждает согласованность приложенных PDF/PNG, но само по себе не доказывает процесс получения PDF из PPTX. Новый экспорт в нашем окружении не выполнен успешно.

Исходный Findings.md в пакете совпадает с нашим файлом. Приложенный тестовый PPTX содержит нативные фигуры и текстовые элементы; это не комплект полноэкранных растровых слайдов. Совместимость с Microsoft PowerPoint и поведение объектов при редактировании в нём не испытаны.
